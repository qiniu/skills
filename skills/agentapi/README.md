# AgentAPI 技能

在项目目录执行以下命令，即可安装或更新七牛云 AgentAPI 技能。

```sh
npx skills add qiniu/skills --skill agentapi
npx skills update agentapi
```

编码助手可根据任务选择 Portal 或 API 接入方式，并确定运行时和执行环境。具体接口、示例和术语说明见七牛开发者中心。[使用指南](SKILL.md) · [文档索引](references/INDEX.md)
