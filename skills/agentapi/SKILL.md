# 使用七牛云 AgentAPI

七牛云 AgentAPI 提供托管的智能体运行服务，适合需要多次调用工具、持续交互或跟踪执行进度的任务。可以将模型、指令和工具配置为可复用的智能体，在指定环境中通过会话执行任务，并获取回答和文件。单次文本生成、信息提取或分类，通常可直接调用模型推理 API。

## 接入前确认项目配置

- **接入已有项目时**，先查看服务端代码、依赖版本和配置。确认服务地域、正在使用的智能体和执行环境，并了解应用如何保存会话 ID。尽量复用已有资源，沿用项目的 HTTP 客户端、SDK 和密钥管理方式。
- **首次验证时**，选择一项能代表实际业务的任务，明确输入、所需工具和验收标准。可以先在 Portal 验证配置和执行结果。需要接入业务系统时，按 API 快速入门选择 HTTP 接口或受支持的 Anthropic SDK。
- **调用服务前**，核对服务地域、模型使用权限和资源归属。应用应记录业务任务与会话的对应关系，并从服务端的密钥配置中读取 API Key。

## 根据任务选择方案

选型时，先明确任务要用哪些工具、需要哪些权限、结果怎样交付。例如，定期生成报表可能同时用到定时部署和文件交付。如果有多个运行时可选，用同一项任务比较可用工具、执行质量和耗时。

| 任务需求 | 接入建议 |
| --- | --- |
| 批量处理文件、核对数据或生成报告 | 将输入文件附加到会话，约定输出格式，再通过 Portal 或文件接口获取产物。 |
| 定期核对订单或生成巡检摘要 | 先手动验证一次，再配置定时部署。应用可按业务日期或任务 ID 避免重复处理，并根据运行记录核对结果。 |
| 代码审查或仓库维护 | 需要沿用已有编程工具链时，选择由 Claude Code SDK 驱动的 `claudecode` 或由 Codex harness 驱动的 `codex`，并核对云端环境和仓库权限。审查规范可以通过 Agent Skills 复用。 |
| 展示执行进度或接收后台通知 | 通过 SSE 展示会话进度。需要在后台接收状态通知时，使用 Webhook，并在收到通知后查询本轮执行结果。 |
| 接入外部系统，或由应用执行和审批工具调用 | 如果 AgentAPI 服务端能够访问远程工具，可以通过 MCP 接入。应用需要执行自定义工具、回传结果或审批调用时，优先评估 `native`，并核对工具权限。 |
| 在内网查询数据或执行运维任务 | 使用 `native` 和自托管执行器，由 worker 在内网执行文件操作和命令。模型请求仍由 AgentAPI 发起。先核对工具结果的流向，再通过 worker 上的业务工具访问内网服务。 |

## 查阅相关文档

从[文档索引](references/INDEX.md)查找当前任务所需的页面。在控制台配置和测试智能体时，查阅「在 Portal 中构建」。编写接入代码时，查阅相关指南和 OpenAPI 规范，并核对项目安装的 SDK 版本与类型定义。发现差异时，说明具体差异和仍需确认的内容。

## 验证实际执行结果

1. 提交有代表性的输入，记录会话 ID，确认能查询本轮进度。需要持续接收事件的应用，应按文档处理历史回放和重复事件。
2. 查看本轮停止原因，再验收业务结果。任务因工具调用而暂停时，按权限策略处理待审批的调用，或将工具结果回传给会话。如果要求交付文件，下载后检查内容，例如确认报告覆盖了指定日期。

SSE 连接断开后，先恢复事件接收或查询会话历史，确认原任务是否已被接收，再判断是否需要重新提交。交付时说明已验证的任务、结果和待验证的环节。
